# Kalendarium

Persönlicher Kalender als Web-App: Stundenplan, Fristen, Wege mit Puffer, automatischer Schlafplan, Wetter (Open-Meteo).

**App öffnen:** https://slesta21.github.io/kalendarium/

Auf Android in Chrome öffnen und „App installieren“ wählen. Die Termine liegen nur auf deinen Geräten und, wenn eingeschaltet, in einem privaten GitHub-Gist für den Abgleich.
